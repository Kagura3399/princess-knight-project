# Princess Knight Project

> **An immersive RPG-style task management app that turns real-life tasks into quests.**

**Princess Knight Project** 是一款以 RPG 遊戲概念設計的個人化待辦事項管理 App。

本專案最初是為了協助我的男朋友記錄日常生活中的待辦事項，
但我不希望它只是另一個單純的 To-Do List。

因此，我嘗試將「現實生活中的待辦事項」轉換成 RPG 世界中的「任務（Quest）」，
讓使用者不只是把事情打勾完成，而是以冒險者的身份，
一步一步完成每天的任務。

---

# Project Concept

一般的待辦事項管理方式通常是：

```text
□ 完成報告
□ 整理房間
□ 運動
□ 處理明天的行程
```

Princess Knight Project 希望把它重新設計成：

```text
⚔ Quest Log

Main Quest
完成今天的報告

Side Quest
整理房間

Daily Quest
運動 30 分鐘
```

核心概念為：

```text
Real Life
   ↓
Gamification
   ↓
RPG World

待辦事項 → Quest
完成事項 → Quest Complete
每天生活 → Daily Adventure
使用者 → Player / Adventurer
```

讓原本較枯燥的生活管理，
變成具有故事感、沉浸感與成就感的 RPG 體驗。

# Project Motivation

這個專案的起點其實非常簡單：

> 希望做一個可以幫重要的人記住每天要做什麼的工具。

生活中的待辦事項經常散落在聊天訊息、備忘錄或其他平台，
有時候即使記錄下來，也很容易因為缺乏動機而一直拖延。

因此，我開始思考：

> 如果完成現實生活中的事情，
> 可以像完成 RPG 遊戲任務一樣有成就感，
> 會不會讓待辦事項變得更有趣？

於是便有了 **Princess Knight Project**。

它不只是記錄事情，
而是希望把每天的生活變成一場持續進行的冒險。

# Core Features

## 1. RPG-style Task Management

Princess Knight Project 最大的特色，
是將一般待辦事項重新包裝為 RPG 任務。

例如現實中的：

```text
完成作業
整理房間
準備報告
處理行程
```

在 App 中可以被理解為：

```text
Main Quest
Side Quest
Daily Quest
Special Quest
```

使用者完成現實生活中的事情，
就如同完成遊戲中的一項 Quest。

---

## 2. Immersive RPG Experience

本專案並不是單純將待辦事項換一個名稱。

設計重點是希望建立一個具有：

- RPG 世界觀
- 任務系統
- 遊戲式操作體驗
- 故事感
- 個人化
- 完成任務的成就感

的日常管理工具。

讓使用者進入 App 時，
不是感覺自己正在「處理工作」，

而是：

> 開始今天的冒險。

---

## 3. Personalized Experience

本專案最初即針對特定使用者的生活需求進行設計。

因此在開發過程中，
不只考慮程式能否執行，
也會考慮：

- 使用者是否容易理解
- 操作方式是否直覺
- 功能是否真的有使用價值
- 資訊是否清楚
- 使用流程是否自然
- 是否願意長期使用

這也讓本專案從單純程式練習，
逐步轉變成一個以使用者需求為核心的作品。

# How to Play

Princess Knight Project 的使用方式，
就像每天登入一款 RPG。

---

## Step 1 — Enter the World

開啟 App 後，
使用者進入 Princess Knight 的世界。

每天的生活，
就像開始新的一天冒險。

```text
Welcome Back, Adventurer.
```

---

## Step 2 — Check Your Quest Log

查看目前需要完成的任務。

每一項現實生活中的待辦事項，
都可以被視為一項 Quest。

例如：

```text
Main Quest
完成期末報告

Side Quest
整理房間

Daily Quest
運動 30 分鐘
```

---

## Step 3 — Complete Real-Life Tasks

接著回到現實生活中，
真正完成這些事情。

這個 App 的核心並不是讓使用者一直待在手機裡，
而是讓遊戲成為完成現實目標的動力。

---

## Step 4 — Quest Complete

完成現實中的事項後，
回到 App 將任務標示為完成。

```text
Quest Complete!
```

相較於一般待辦事項只有：

```text
✓ Done
```

Princess Knight 希望讓完成事情的瞬間，
更接近遊戲中完成任務時的成就感。

---

## Step 5 — Continue Your Adventure

完成一個 Quest 後，
繼續下一個任務。

```text
Quest
  ↓
Complete
  ↓
Next Quest
  ↓
Progress
  ↓
Another Adventure
```

每天的生活，
就變成一場持續累積的冒險。

# What Makes It Different?

一般 To-Do App 的核心通常是：

```text
記錄
↓
提醒
↓
完成
```

Princess Knight Project 則希望加入：

```text
Task Management
        +
RPG Game Design
        +
Gamification
        +
Personalized Experience
        ↓
Princess Knight Project
```

最大的差異並不是「功能更多」，
而是**使用體驗不同**。

本專案希望讓使用者從：

> 「我還有好多事情沒做。」

轉變成：

> 「今天還有哪些 Quest 可以完成？」

# User-Centered Design

本專案其中一項重要學習，
就是從單純的「寫程式」轉向：

> 「設計一個人真的會使用的系統。」

在開發過程中需要考慮：

```text
User Need
   ↓
Feature Planning
   ↓
UI Design
   ↓
Programming
   ↓
Testing
   ↓
User Feedback
   ↓
Optimization
```

因為實際使用者就是身邊熟悉的人，
因此可以直接觀察實際操作狀況，
並依照回饋持續改善系統。

---

# Development Process

本專案主要依照以下流程進行：

```text
01 發現生活需求
        ↓
02 定義專案目標
        ↓
03 RPG 世界觀與功能構想
        ↓
04 UI / 操作流程設計
        ↓
05 程式開發
        ↓
06 功能測試
        ↓
07 實際使用
        ↓
08 Debugging
        ↓
09 功能改善
```

與一般課堂指定題目不同，
本專案沒有預先提供完整答案或固定功能要求，

而是需要自己決定：

- 要解決什麼問題
- 使用者需要什麼
- 功能應該如何設計
- 操作流程應該如何安排
- 出現問題時如何除錯
- 哪些功能值得繼續改善

# What I Learned

這個專案讓我了解到：

> 程式設計的價值，不只是「程式能不能執行」，
> 而是能不能真正解決一個人的需求。

即使看似只是一個待辦事項 App，
實際進行開發時仍需要考慮：

- 資料如何呈現
- 使用者如何操作
- 介面是否容易理解
- 功能流程是否合理
- 發生錯誤時如何處理
- 使用者是否願意持續使用
- 如何讓一個普通功能產生不同的體驗

而將 RPG 元素加入待辦事項管理，
也讓我開始接觸「Gamification」的概念。

也就是：

> 利用遊戲設計中的任務、回饋、成就與成長機制，
> 提升使用者參與一般非遊戲活動的意願。

這讓我從：

```text
「如何完成一個程式」
```

逐漸開始思考：

```text
「如何設計一個真正有人願意使用的產品」
```


能夠以視覺化方式呈現在角色成長上。

---

## Reward System
